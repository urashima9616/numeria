## 1. Vision 与玩家画像

**一句话**:一款为 5 岁孩子设计的宝可梦式 RPG(iOS,像素风大地图 + 2D 动画战斗),在这个世界里**数字与图形本身就是魔法**——孩子通过解开数学谜题释放强力技能、暴露敌人弱点、开启宝箱与完成进化,数学永远是让你变强的力量,而不是拦路的考试。

### 玩家画像

- **年龄**:5 岁男孩
- **数学水平**:已掌握 10 以内加减法;20 以内加减法练习中;对图形、对称、规律有浓厚兴趣
- **语言**:英文游戏。全程英文语音旁白 + 图形化提示;玩家能读简单英文句子,识字量有限,关键信息不依赖阅读
- **操作**:iPad 触屏,以拖拽和点击为主,不要求书写

### 设计三原则

1. **零惩罚(Zero-Punishment)**:答错数学题**不掉血、不受罚**——技能仍以基础威力释放。系统用十格阵数块动画做可视化提示,引导重试一次;重试答对依然触发满威力效果。数学永远是加成(bonus),从不是门槛(gate)。
2. **数学是魔法,不是测验**:谜题以"咒语""封印""符文锁"的形式出现在世界观内部,没有任何"跳出游戏做题"的时刻。
3. **听得懂就能玩**:所有题目配英文语音旁白("Three plus what makes seven?"),UI 以数字、符号($+$、$-$、$=$)和图标为主。

## 2. 核心循环(Core Loop)

```
探索地图 → 遭遇野生数灵 → 战斗(数学高潮点)
   ↑                              ↓
解锁传送门 ← 升级/进化 ← 开数学宝箱 ← 获得经验·金币·材料
```

每一圈循环中,数学以三种"浓度"出现(见第 3 节),孩子在 5–10 分钟的一次冒险里自然完成 10–20 次数学微练习而毫无察觉。

---

## 3. 三层数学融入模型(本设计的灵魂)

| 层 | 名称 | 数学如何出现 | 是否要求"答对" |
|---|---|---|---|
| L1 | **环境层** · 无意识浸泡 | HP 条画成十格阵(ten-frame);金币逐个数着捡;地图上编号的门;地砖藏着 ABAB 规律纹样 | 否,纯浸泡 |
| L2 | **决策层** · 轻数学策略 | 能量宝石系统:技能标注消耗(⚡×3),孩子盘算"我有 5 颗,放完还剩几颗" | 否,算错只是战术亏 |
| L3 | **高潮层** · 显式谜题 | 大招咒语算式、凑十破盾、图形锁宝箱、进化试炼、收服友谊谜题 | 是,但零惩罚可重试 |

**节奏控制**:每场普通战斗出现 2–3 次 L3 谜题,确保情绪高点与数学时刻重合;L1/L2 无处不在但永不打断游戏流。

## 4. 战斗系统(回合制 · 2D 动画演出)

### 4.1 回合结构

- 双方轮流行动;玩家侧同时上场 1 只数灵,可随时切换(不耗回合,降低决策压力)。
- 每回合开始自动获得 2 颗能量宝石(上限 8),技能按稀有度标注消耗 ⚡×1 / ⚡×3 / ⚡×5。

### 4.2 行动选项

| 行动 | 数学层 | 说明 |
|---|---|---|
| 普通攻击 | L1 | 零门槛保底,永远可用,伤害数字大而清晰地跳出 |
| **强力技能(咒语算式)** | L3 | 见 4.3 |
| 破盾(凑十法) | L3 | 见 4.4 |
| 换数灵 / 用道具 | L2 | 道具数量逐个数,背包格子编号 |

### 4.2.1 攻击、防御与血量

- 每只数灵都有清楚显示的 **ATK** 与 **DEF**。基础伤害为 `ATK − DEF + 1`,每次只做 `−1 / 0 / +1` 的小幅波动,最低始终为 1;孩子能观察“攻击高打得多、防御高受伤少”,随机性不会盖过策略。
- 升级每级 ATK +1,每逢偶数等级 DEF +1;武器提升攻击,护符/戒指/盾提升防御。
- 普通怪 HP 随遭遇浮动:第一关 8–12,第二关 14–20,第三关 22–30。
- Boss 使用可预期的递增曲线:20 → 36 → 54 HP,并同步提高 ATK、DEF 与护盾目标。

### 4.3 强力技能 = 咒语算式

1. 点击技能图标 → 画面暗下,浮现咒语算式,例如 $3 + \square = 7$
2. 屏幕下方漂浮 3–4 颗**候选数字水晶**(如 2、4、6、9)
3. 语音旁白同步读题:"*Three plus what makes seven?*"
4. **拖拽**水晶填入空格:
   - ✅ 答对 → 水晶炸裂,全屏大招动画,满威力伤害 + 属性特效
   - ❌ 答错 → 技能仍以基础威力释放(零惩罚);同时浮现十格阵数块动画(3 个亮块 + 需要几个才到 7),引导**重试一次**;重试答对依然放出满威力大招

候选水晶数量与干扰项相似度由自适应引擎控制(见第 9 节)。

### 4.4 破盾机制(凑十法)

精英怪与 Boss 携带**数字护盾**,盾面显示盾值(如 **10**)。玩家从手牌数字卡(如 2、3、7、5)中**选两张凑成盾值**($3+7=10$)→ 护盾碎裂,之后 2 回合敌方受到双倍伤害。这直接训练"凑十法"这一进位加法的核心策略。

### 4.5 Boss 战

Boss 拥有**多段护盾**,每段对应一种题型,像音乐游戏一样有节奏段落感:

> 第一段:算式填空 → 第二段:凑十破盾 → 第三段:图形规律
> 每破一段,Boss 形态受损、演出升级,最终大招终结。

### 4.6 收服机制(友谊谜题)

把野生数灵打到低血量(HP 十格阵只剩 1–2 格)后,它头顶浮现一道**友谊谜题**;答对即被感化收服,伴随爱心动画。收服本身就是一次数学时刻,且与"削弱 + 精灵球"的经典体验同构。

## 5. 题型库(按地图 × 题型)

### 🌲 神秘森林(Mystic Forest)— 舒适区,建立自信

| 题型 | 示例 | 语音旁白示例 |
|---|---|---|
| 10 以内加法填空 | $3 + \square = 7$ | "Three plus what makes seven?" |
| 10 以内减法填空 | $9 - \square = 5$ | "Nine take away what leaves five?" |
| 点数 | 数出屏幕上的萤火虫:🪲×6 | "How many fireflies do you see?" |
| 数量比较 | 左边 5 只蘑菇 vs 右边 8 只,哪边多? | "Which side has more mushrooms?" |
| 图形识别 | 从四张图形卡中找到三角形 | "Find the triangle!" |
| 对称 | 为单个图形找到镜像另一半 | "Find the matching wing!" |
| 入门规律 | ABAB / AABB 选下一个 | "What comes next in the pattern?" |

### ⛰️ 静寂山脉(Silent Peaks)— 成长区,主练习场

| 题型 | 示例 | 语音旁白示例 |
|---|---|---|
| 20 以内加减 | $13 + \square = 17$ | "Thirteen plus what makes seventeen?" |
| 凑目标 | 从候选数中选两张凑成 $20$ | "Pick two crystals that make twenty!" |
| 连加 | $2 + 3 + 4 = \square$ | "Add them all up!" |
| 中级规律/对称 | ABC 循环、按边数识图、向右转 1 次 | 图形语音提示 |

### ☁️ 蔚蓝天空城(Azure Sky City)— 30 以内综合区

| 题型 | 示例 | 语音旁白示例 |
|---|---|---|
| 30 以内加减 | $18 + \square = 27$ / $30 - \square = 19$ | 完整数字语音读题 |
| 四项连加 | $3+4+6+5=\square$ | "Add them all up!" |
| 高级图形规律 | ABCD ABC❓ 选下一个 | "What comes next in the pattern?" |
| 对称/旋转 | 镜像匹配、向右转 2–3 次 | 图形语音提示 |
| 数列 | 按 2–5 递增且结果不超过 30 | "What number comes next?" |

## 6. 数灵阵容(Mathmon Roster,首发 15 只)

### 御三家(三段进化,9 只)

| 进化线 | 属性 | 谜题亲和 | 代表技能(题型) |
|---|---|---|---|
| **Addmander → Sumdrake → Equadragon** | 🔥 火 | 算式填空 | Flame Formula(加法填空)→ 进化后 Blaze Equation(20 以内) |
| **Tenfin → Decaqua → Tidalten** | 💧 水 | 凑十/组合 | Splash Ten(凑十选卡)→ 进化后 Tidal Combo(三数凑目标) |
| **Shapling → Pattervine → Geoflora** | 🌿 草 | 图形规律 | Leaf Pattern(ABAB 规律)→ 进化后 Bloom Symmetry(对称) |

### 地图特色野生线(两段进化,6 只)

| 进化线 | 出没地图 | 属性 | 谜题亲和 |
|---|---|---|---|
| **Countipillar → Numberfly** | 🌲 神秘森林 | 🐛 虫 | 点数、数量比较 |
| **Doublit → Duplirock** | ⛰️ 静寂山脉 | 🪨 岩 | 翻倍、连加 |
| **Mirrowl → Symmetrix** | ☁️ 蔚蓝天空城 | 🕊️ 飞行 | 对称、旋转 |

命名原则:数学词根 + 生物词根(Add+salamander、Ten+fin、Mirror+owl),孩子念出名字时就在复述数学概念。

## 7. 地图、传送门与 DLC 架构

### 线性解锁

**神秘森林 → 静寂山脉 → 蔚蓝天空城**,由传送门链接。

- **传送门钥匙** = 击败该地图 Boss + 解开一道**综合谜题**(混合该地图全部题型的三连题,零惩罚可重试)
- 已解锁的地图可随时传送回去自由冒险(舒适区刷级、找漏掉的宝箱)

### 数据驱动的 DLC 架构

地图、题库、数灵、掉落全部为 **JSON 配置**,不写死在代码里:

```
content/
  maps/forest.json        # 场景、NPC、宝箱位置、遭遇表
  puzzles/forest.json     # 该地图题型池与难度参数
  mathmon/roster.json     # 15 只数灵的属性/技能/进化链
  items/equipment.json    # 装备数值与掉落表
```

未来 DLC(如"齿轮沙漠"教乘法萌芽)只需新增一组配置文件 + 美术资源,零代码改动。

## 8. 养成系统

### 8.1 升级

- 战斗获得经验;升级时属性数字**跳动放大**并配语音:"*Attack goes from 8 to 10!*" —— 把读数字变成仪式感。
- 属性刻意保持小数字(个位数到 20 以内),让孩子能亲自心算成长量。

### 8.2 进化(三条件)

1. **等级达标**(御三家:Lv.8 → 二段,Lv.15 → 三段)
2. **进化石**:藏在地图谜题之后(如推开刻着 $12 - 4 = \square$ 的封印石门)
3. **进化试炼**:3 道该数灵谜题亲和主题的题目(火系=算式、水系=凑十、草系=图形),零惩罚无限重试

通过后播放进化动画:形态蜕变、旧技能威力升级、习得一个新强力技能。**进化 = 数学能力的里程碑证书**。

### 8.3 数学宝箱与装备

- 宝箱散落各地图,**锁就是谜题**(题型随地图);稀有宝箱为三连题。
- 开出**武器 / 防具 / 饰品**,数值刻意简单:`Sword +2 Attack`、`Shield +3 Defense`。
- 装备时 UI 展示算式 $8 + 2 = \square$,孩子心算确认后数值才跳到 10 —— **穿装备也是一道加法题**。

## 9. 自适应难度引擎与家长面板

### 自适应引擎(隐形)

- 记录每道题的**正误与作答用时**,按题型维护掌握度分数。
- **错题变形复现**:答错的题型会在之后战斗中换个数字、换个皮肤再次出现(间隔重复原理),绝不标注"你上次错了"。
- 连续答对 → 悄悄升一档(数字变大、干扰项更接近);连续犹豫或出错 → 悄悄降一档。曲线完全隐形,孩子只感觉"我一直在赢"。

### 家长面板(设置内 PIN 门)

- 各题型**掌握度热图**(森林/山脉/天空城 × 题型)
- 游戏时长统计与单次时长提醒(默认 20 分钟温柔提示:数灵想睡觉了)
- 难度上下限手动调节(覆盖自适应引擎的边界)
