## Dynamic Music

Numeria can use selected tracks from the locally installed **Dynamic Music** Unity Asset
Store package. The original package and synchronized runtime WAV files are intentionally
excluded from this public repository. Owners can import the package and run
`Numeria > Audio > Sync Dynamic Music`; the editor also attempts this sync automatically.

The music remains governed by the Unity Asset Store license attached to the user's local
package. It is not redistributed as repository source content.
