# Afterstory generated art

Generated with the built-in ImageGen tool for Numeria on 2026-09-13. These are original project assets, not Asset Store tiles. No third-party source pack was modified.

## Import and review
Creature sheets were regenerated by ImageGen where a painted checkerboard appeared instead of actual transparency. Only final RGBA sheets were selected. `AfterstoryAssetImporter` mechanically splits connected creatures and fits each on a 512×512 transparent canvas. Per-component ownership prevents long tails in neighboring cells from leaking into another icon. This does not redraw the creatures. Existing game art is untouched.

Normal and Mega sheets each contain three distinct forms. Every new form has both `generated/<id>_large_icon.png` and `generated/<id>_mega_icon.png`. The importer is optional tooling; committed single-sprite PNGs are sufficient to run the game.

## Battle backgrounds

Outputs: `unity/Assets/Resources/generated/Backgrounds/Painted/Ancient_Ruins.png` and `Veilmoon_Lake.png`.

Art-direction record (not a verbatim prompt transcript): the ruins are a warm ivory observatory courtyard with bronze instruments, turquoise mosaics, ivy and open combat ground; the lake has indigo water, moonlit willows, lotus, gold lanterns and a quiet pavilion. Both omit creatures, text and UI. Actors use explicit per-background ground coordinates in `BattleStageLayout`, not a stretched generic backdrop.

The new scenes reuse licensed existing Jukebox moods (Sky for ruins, Mountains for lake), with the existing crossfade and narration ducking. No new music was generated.
