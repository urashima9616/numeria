# Eight Depths generated assets

Generated September 25, 2026 with the built-in ImageGen tool, one call per creature (not the API/CLI fallback). Original generation outputs remain in Codex generated_images; the game uses only the copies in this repository. Transparent RGBA sources are preserved. Unity imports new portraits at a maximum of 512 px, point filtering, no mipmaps; the field-guide tab icon is limited to 128 px.

Style reference: `unity/Assets/Resources/generated/symmetroak_large_icon.png` (style only, not a character to duplicate).
